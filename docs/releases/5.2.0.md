# Etched 5.2.0

Etched for Minecraft 1.21.1 on NeoForge and Fabric.

## What's new

- Etched now supports Fabric. The mod is built from one codebase for both loaders. Sophisticated Core support stays NeoForge only.
- SoundCloud tracks play again, including the AAC over HLS streams SoundCloud now serves, and AAC audio can be played from any URL.
- Radios and long tracks no longer freeze the game when the network is slow. A stalled live stream plays silence until it catches up instead of rewinding.
- Requests to addresses on private networks or this computer are blocked, including redirects. The client option `Allow Private Network Stations` allows them for stations on your own network.
- Google Drive and Dropbox share links are converted to direct download links.

## Files

- `etched-neoforge-1.21.1-5.2.0.jar` for NeoForge 21.1 or newer
- `etched-fabric-1.21.1-5.2.0.jar` for Fabric Loader and Fabric API, with Forge Config API Port

Check the `.sha256` files to verify your download.
